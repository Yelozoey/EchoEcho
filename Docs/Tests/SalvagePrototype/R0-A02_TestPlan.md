# R0-A02 适配测试计划

2026-10-28；详细处理参数见 `Docs/SalvagePrototype/R0-A02_AssetAdaptation.md`。I/P/V三个内部模块顺序执行，分别报告。

| 子模块/用例 | 操作 | 期望 |
| --- | --- | --- |
| I01 复制完整性 | 重算进入Assets的源FBX/纹理SHA，与原始清单和ZIP成员核对 | 原始源字节不变；派生Mask独立命名 |
| I02 模型 | 读取真实ModelImporter、Mesh与实例Renderer | 文件单位、scale=1、次级UV；Mesh非空，法线/UV/切线存在；记录实际面数 |
| I03 比例 | 实例地板测bounds，与源glTF对比；记录工具箱bounds | 地板X/Z约4m，Y约0；工具箱正尺寸且没有100倍错误 |
| I04 贴图与Mask | 检查导入色域、正常图类型、压缩/MipMap、原始与派生通道样本 | 线性/颜色通道正确，无roughness当smoothness错误 |
| I05 材质 | 读取两份实际URP Lit材质与Shader状态 | 正确地图/关键词、Shader无错误，不留Standard粉材质 |
| P01 预制体 | 实例化两个已保存prefab | identity包装、源材质替换、碰撞与Renderer对应 |
| P02 地板碰撞 | 在板内/边界外发实际Collider射线 | 板内命中顶面，外部不命中，不使用任意大盒掩盖比例 |
| P03 工具箱碰撞 | 从多个方向对实际BoxCollider发射线 | 命中对应物件，外部射线不中，不宣称动态物理已验证 |
| P04 模块拼接 | 同模型放在相邻4m网格，比较实际bounds | 边界对齐，无缩放补丁 |
| V01 独立场景 | 重新打开拥有的展示场景并检查实际配置 | 普通Forward/HDR/SDR/D3D11，所有对象/材质有效 |
| V02 实际画面 | 渲染地板全景、工具箱近景与地图开关对照 | 非黑、无粉材质，地图影响真实像素；保存原始图与统计 |
| V03 清理与还原 | 结束测试、恢复原布局/绑定/AA/播放选项，重算旧文件SHA | 用户旧文件不变、无临时GPU资源/材质残留 |

测试只验证两件资源的工程适配，不代表正式场景、烘焙、LOD、手持玩法或最低配置性能已通过。
