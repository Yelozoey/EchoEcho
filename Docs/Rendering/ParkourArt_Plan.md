# 跑酷美术场景独立制作记录

2026-10-27（Asia/Shanghai）。用户本轮明确委托完整独立完成基础几何体城市跑酷场景、纯色简化PBR、普通URP Forward、日光/干净阴影、区域烘焙探针、平面反射和仅颜色类后处理。该委托只作用于本场景，不推进EchoStation的S4、不修改S1–S3玩法、Prompt或模型。

## 规划与边界

- 工作目录 `Assets/EchoStation/ParkourArt/`；入口 `Scenes/ES_VectorCity_Parkour.unity`。
- 主体约80×90m，含外围城市背景约120×120m；米制。五个主屋顶从12m上升到20m，白色起跑、红色加速/跳台、青蓝玻璃庭院、白色高台、终点。主路线约100m，跳口1–3m，坡道上升2–3m。
- 白/暖白约70%，青蓝约18%，中灰约9%，红色约3%；每个屋顶一个大主色，红色连续引导。构件仅Unity Cube/Plane/Cylinder；硬边、无碎物/复杂曲面/细碎管线，无外部模型。
- Albedo纯色；无Normal/Detail/磨损AO/roughness贴图。Shader采用URP的连续GGX PBR光照与IBL、常量粗糙度、金属参数；不用描边/量化阴影。玻璃采用干净着色的建筑反射面，不加入污渍。
- 专用Pipeline/Renderer/Profile；场景打开时限定使用本场景管线，退出时按原资产引用还原。保留PC/S2基线文件。内部HDR→SDR，D3D11，1080p；不修改显示器HDR。
- 阴影4096、4级CSM、约110m、确定性PCF；SSAO关闭。明亮环境SH与日光；不烘焙噪点式AO。后处理仅ColorAdjustments/WhiteBalance等颜色控制，不开启颗粒、色差、暗角、景深、Bloom或镜头效果。
- 区域反射探针实际烘焙；URP需自行实现镜像相机+裁剪平面+RenderTexture的平面反射，受Fresnel/常量粗糙度控制，避免递归，限定可见反射面和分辨率。

## 顺序与门禁

1. PK01：基础几何、路线/碰撞与专用场景；独立几何检查并归档。
2. PK02：Shader/材质；实际编译与连续PBR图像验证后归档。
3. PK03：专用Forward管线、日光、阴影与环境；实际图像/设置检查。
4. PK04：区域探针、实际烘焙和平面反射；真实开关对照、持久化和资源清理检查。
5. PK05：仅颜色Volume；实际图像、自查、交付说明和保护资产核验。
