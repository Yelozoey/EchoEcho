# S1 性能记录与诊断阈值

## 方法与真实结果

## 已落地的优化证据

- 静态源网格按室/材质/烘焙条件30→8合并体，UV2与碰撞验证；Lightmap2方向图集/141探针，关烘焙灯图差0、移除Lightmap变黑。
- 独立PVS5728字节；最终受控Windows相机对照Draw Calls19→12，同状态基线与剔除开关图差均0。对照临时关闭时变后效/实时灯/动态表现，finally还原；上述正常画质900帧仍包含实际手电、SSAO、颗粒与Echo。不能将受控19→12冒充正常画质的总Draw Calls。
- 动态SRP Batcher/实际CSM与近远投影、扫描单全屏Pass/空闲0 Pass、固定粒子预算均有各自模块实际测试，见R04/R05/E11/E12/E13报告；产品没有为展示池添加粒子。
- 原始GC栈定位两次20B枚举装箱/帧和128B感知委托/约.2s，改成无装箱校验与缓存Predicate。相同仪表控制轮45696B→96B；余下96B来自夹具首次取样，实际API预热后最终900帧全部0B。不是仅凭代码推断。

## 开发期诊断阈值与限制

S1持续授权内采用主线程P95<8ms、渲染线程P95<4ms、GPU P95<12ms、常态业务循环0B GC/帧、使用内存<1.5GiB、单视点Draw Calls<200作为当前原型报警线；这是预留预算，CPU/GPU流水并行，不能串行相加解释。窗口60FPS节流统计P50/P95/P99/最大帧，不删除不利帧。

最低目标仍为i5-8400/GTX1060 6GB/16GB中画质1080p60FPS；推荐i5-12400/RTX3060 6GB/16GB高画质1080p60FPS。本机结果不能替代这两台实机验收。900帧为三个稳定视点，完整峰值扫描/加载/长时游玩及最低硬件仍需阶段4测试；高/中/低预设、Addressables五区流送、植被/Impostor与局部体积效果按后续阶段落实。
