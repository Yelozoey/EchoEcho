# S2 M05 手工关键词相关片段检索

M04独立通过后实施，遵守已确认的手工关键词/同义词方案，不引入分词或向量模型。

输入为固定MemorySnapshot和最多200字符的问题。索引为作者配置的同义词组和针对稳定ID的别名，查询只遍历已知快照；索引中存在某个未发现线索的别名不等于允许返回它。中文按完整关键词子串匹配，最短2字符；ASCII词与稳定ID增加词边界，避免power_panel_01误命中power_panel_01_extra。

普通实现参数：直接ID命中100分，完整标题或显式已知密码/标记命中30分，每个相关同义词组10分，目标专属别名命中20分。相关组必须同时命中问题和该记录的已知文本，专属别名只指向对应类别/ID；同组多个同义词不重复计分。无相关命中返回空，不因优先级高而灌入无关历史。排序按相关分降序，平分按类别和稳定ID，保证确定性。目录最多64组/1024别名，每组1–16个2–32字符词，构造时复制并拒绝同身份别名重复。

M05只返回相关的不可变数据引用及分数，不拼Prompt，不控制GameObject，不在Update常驻轮询。事件使用事件摘要，线索使用标题/摘要和已知密码/标记，角色使用摘要/关联目标；没有FullText入口。M06再做时间降权和最多8条/1200 UTF-8字节限制。

独立用例：中文同义词、精确ID及边界、别名、无匹配、未知线索隔离、同组去重、确定性排序、输入长度/非法索引、复制外部索引数据、三类记录与固定快照、原文不入结果。实际新增10项连回归48/48通过，见[报告](../Tests/Stage2/Reports/S2-M05_MemoryRetrieval_TestReport.md)，证据Evidence/S2-M05，可进入M06。
