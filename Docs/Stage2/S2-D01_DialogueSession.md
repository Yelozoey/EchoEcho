# S2 D01 消息与会话数据

M01–M07独立通过后实施。只建立无引擎依赖的数据程序集和有界会话，不建UI、不执行指令。

采用已确认的玩家输入200字符、Echo回复280字符、显示最近100条、保存最近50条。角色仅Player/Echo，refuse作为Echo消息标记；空白不提交，成功消息去除首尾空白，长度按原始C#字符数判断。消息编号为递增正整数，容量满后仅移除最老的UI历史，不删除记忆或进度。

普通实现细节：消息对象不可变，列表只读，导出最近50条是固定快照；恢复最多50条，编号严格递增但可从任意正整数开始，之后接续最后编号。先校验全部再替换，只发Replaced而不逐条触发Added。Reset清UI历史并重置编号，会话版本递增。台词仅作为字面文本，rich text关闭由D02实际UI验证；不把对话全文当记忆上下文。

独立用例：角色/拒绝、空白/长度边界、消息顺序、100条淘汰、50条快照/接续、非法恢复不部分应用、Reset与通知、只读/外部数据隔离及无引擎引用。2026-10-25独立8/8通过，见[报告](../Tests/Stage2/Reports/S2-D01_DialogueSession_TestReport.md)，证据Evidence/S2-D01，可进入D02。
