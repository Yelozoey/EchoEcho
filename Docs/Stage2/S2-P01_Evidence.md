# S2 P01 笔记互证

A先实现独立于GameObject的六谜题进度集合与互证规则；PZ01必须两份入口来源，PZ06必须三份事故来源及PZ05完成，始终需要玩家明确确认；仅阅读不自动完成。无序/重复/缺来源/非法ID独立测试。

B再将两项核对按钮接入J日志面板：资料未齐时按钮不可确认并显示来源数量，齐全后玩家确认才产生进度与简短事件。完成后不可重复刷事件，不开门或修改供电。摘要仅回到记忆，原文继续由日志显示。

进度将使用独立PuzzleProgress作为游戏事实，记忆记录相应摘要事件；F01统一检查两者一致与全部前后置。为避免普通指令填满512事件妨碍通关，F01将为5区首次访问、6谜题和1结局预留12条事件空间，普通指令记录满500时提示而保留动作执行；不自动删除旧记忆，不改变M01存储容量。
