# S2 W01 五区基础

先A拓扑数据独立测试，再B专用场景、出生/启动/连续导航测试。专用场景Assets/EchoStation/Station/Scenes/ES_Station_Greybox.unity，独立NavMesh与生成资源。S1资产只读取复用，不写入。

拓扑沿Z向推进：山谷-40到-7，小屋-7到4，下降通路4到22（高程0到-4），地下A22到38，通道38到58，核心58到76；下降通路归A区域。宽度分别16/小屋原尺寸/12/5/14米。出生(0,.05,-35)，Echo(1.5,0,-34)。坡度约12.53度、净宽3.2米，适合既有Echo专用Agent；没有瞬移转场。四处过渡可原路返回，未制作正式美术。

W01先作占位地板/连续导航与基础启动，不提前计为各区内容或谜题完成。W02–W06逐区替换/增添边界、线索、设备位置；W03复制既有小屋几何并为出入口改自己的副本。室内静态光照/房间合并与剔除逐区实现和记录；W04/W05保留已确认局部体积接口，真实16步采样及供电消退在P03独立验收后整合。最终全场景实际烘焙不得用参数文案代替。

启动只绑定现有Echo导航/行为树、Player、Journal摘要桥、Dialogue执行与知识回答。UseLLM=false，不使用S1存档组件。区域变化仅产生记忆，不改变机关。F5/F9在F03接统一存档；结局在F02接入。
