# S2 五区灰盒：操作与目标（无答案）

Windows交付入口为`Builds/S2/EchoStation.exe`，运行整个文件夹中的程序，不能只复制exe。Unity编辑器打开`Assets/EchoStation/Station/Scenes/ES_Station_Greybox.unity`后播放。出生在入口山谷，Echo是离线脚本助手，UseLLM=false；本阶段以五区灰盒验证完整流程，正式四区美术与流送在S4。

| 操作 | 键位 |
| --- | --- |
| 移动、视角、跳跃 | WASD、鼠标、空格 |
| 近处读取/设备/门、手电 | E、F |
| 日志/笔记互证 | J；J/Esc关闭，滚轮阅读 |
| 文字对话 | T；Enter发送，Esc关闭 |
| 确定性指令/显示/新局 | Tab；Tab/Esc关闭 |
| Echo跟随、待命、调查眼前目标 | 1、2、3 |
| 手动保存、整体读取 | F5、F9 |
| 释放、恢复鼠标 | Esc、单击游戏画面 |

按入口山谷→小屋→地下A实验室→通风通道→核心控制室前进。读取近处板卡归档日志；两份山谷资料可以在J面板下方核对时间线。小屋找到维护记录，自己输入终端服务码，再E打开地下门。密码正确只授予权限，门仍需你操作。

请Echo“调查储藏室可疑点”，成功后墙上出现向下蓝箭头，台词明确指向地下A区校准架。这不是终点：到地下后继续请它“调查校准架”。Echo必须真正走到可达位置并完成扫描；让开通路，失败时可重试。Tab也可选目标后点调查。两个标记共同提供后续维护凭证，机器人不替你开门或送电。

地下阅读回路说明，E打开供电面板并由你设置/确认。正确后通风密度在3秒内下降、隔离通路开放。通道终端需要已完成真实校准扫描及玩家输入正确维护码，然后E开核心门。

核心可以选择封存撤离；收集并在J核对事故资料后还能选择保留监测，山谷时间线也核对完成则可完整归档。每个结局需选中后再次确认，允许取消并返回补查。结局不自动覆盖手动档；建议选择前F5保存，再F9或结局按钮返回该位置查看其他选择。

文字例句：“跟随我”“等在这里”“调查储藏室可疑点”“调查校准架”“给我提示”“整理线索”“通道终端的密码是多少”。脚本只识别预设中文命令/别名；不认识会请你换说法，多目标会澄清。Echo只回答已发现摘要，已知密码需明确问，输入仍由你完成。指示灯蓝平静、黄调查/扫描、红警戒。

S2档位于`Application.persistentDataPath/Saves/S2/slot1.json`，独立于S1；不自动读档/存档/退出覆盖。新局清空当前运行进度但保留旧手动档，读档后单击恢复鼠标。损坏或未来版本有保护提示，不要通过删除文件绕过诊断。

完整答案与三结局条件见[剧透攻略](Walkthrough.md)。25–40分钟首次体验尚待人类首次游玩计时；自动路线为已知答案操作者，不能当作首次体验时长。
