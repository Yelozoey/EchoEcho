# S2 M07 记忆替换与生命周期

M06独立通过后实施。MemorySession持有当前MemoryStore和递增会话版本；新局重置生成空库，合法恢复生成独立的新库并整体换入，不修改旧库或旧快照。后续请求可持有版本号，版本变化后旧请求不应继续应用；实际异步推理取消属于S3。

恢复先完成JSON解析、完整克隆与可选的调用方一致性校验，失败时当前库、版本、成功通知保持。未来版本、缺失/损坏/IO结果或成功状态但无有效数据均拒绝。成功只发一次Replaced，克隆不会向原订阅者发布逐条新增。快照只读记录可共享，字典/列表不共享。

与M04配合时，日志Replaced先冻结旧知识；F03在全部游戏状态预检成功后提交匹配日志和记忆，再使桥接恢复。M07只验证记忆和日志接口的生命周期，不能替代五区位置、门、机关和全存档原子应用验收。真正新局还须重置世界，最终由场景/流程模块负责。

独立用例：三类合法恢复及版本、非法/未来JSON不部分应用、可选校验拒绝、数据独立、Reset空库/编号、备份结果/无数据拒绝；接口测试确认日志回滚后不再提供旧线索且合法恢复不重复发布新发现。2026-10-25新增8项连纯数据/桥接回归72/72通过，见[报告](../Tests/Stage2/Reports/S2-M07_MemoryLifecycle_TestReport.md)，证据Evidence/S2-M07。
