## A 摘要适配与边界

新建独立 Memory.Integration 程序集引用现有 Player/World 和 Memory 数据层，不修改S1场景。JournalMemoryBridge只接收JournalSummary，禁止接JournalEntry全文。首次绑定只重放已归档摘要，新增条目经SummaryAdded入库。可选已知密码/标记由受控工厂在该条摘要已知时补入；工厂输出ID、标题、摘要和分类必须与源摘要一致，不能引入额外未收集线索。

同步前校验全部已有记忆与日志集合，冲突或多余未知线索拒绝。重放不重复通知。日志Replaced时立即停止提供已知事实，等M07/F03提供匹配的新记忆后恢复；不将读档重建当成新发现。Dispose解绑，重复释放安全。

此模块入库线索类。事件类由后续已确认的游戏进度/玩家操作产生，角色类由明确约定和真实危险认知产生；不从日志全文或玩家声称自动猜测事实。
