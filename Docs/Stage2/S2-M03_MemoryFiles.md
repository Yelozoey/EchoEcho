# S2 M03 本地记忆文件

2026-10-25，M02 独立通过后实施。沿已确认的 S2 单槽、原子提交/备份/损坏保留原则，先测试独立记忆文件组件；F03 最终整合为进度/记忆同次提交，不能在产品中形成两个不同步的事实来源。

文件组件使用调用方显式目录下 memory.json/.bak/.tmp，UTF-8 严格解码、2MiB 上限，tmp 写入后 Flush(true) 再 File.Replace；已有未来版本或双损坏拒绝覆盖。主档损坏而备份有效时回退；下一次写前保留损坏主档的唯一 .rejected 副本，并保持好备份。主档缺失而已有备份时，写入前仍检查备份版本/有效性，防止误覆盖未来版本或丢弃坏文件。

实例锁只保证同一文件组件内调用串行，不宣称跨进程写入安全。文件 IO 在手动保存/加载时触发，不在 Update 轮询。只在 Library/EchoStation/S2-M03/唯一GUID 目录测试，不触及玩家实际存档；清理仅删除核实位于该根下的测试目录。

独立用例：首次真实磁盘往返、第二次原子提交与上版备份、损坏回退、恢复保存留 rejected、双损坏保留、未来主档保留、主档缺失的未来备份保护、锁文件失败保留旧档、tmp 忽略与清理、非法 UTF-8/过大文件、无档状态。2026-10-25新增12项连记忆回归共38/38通过，见 [实际报告](../Tests/Stage2/Reports/S2-M03_MemoryFiles_TestReport.md) 和 Evidence/S2-M03。
