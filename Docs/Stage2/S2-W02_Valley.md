# S2 W02 入口山谷

W01独立通过后实施。原生灰盒围出16×33米山谷，南端封闭、北端收窄至小屋入口3.2米；无植被/碎石，因此不引入未实现的装饰优化。两份已确认原文分别布置在入口巡检台(-4,1.25,-30)与撤离告示架(4,1.25,-14)，前方保留Echo调查点和玩家E读取空间。原文对应独立ClueDefinition，摘要桥只附加已知元数据。

本模块验证边界碰撞、两份真实E读取与日志/记忆入库、返回/导航和原始文案分离；互证确认操作在P01。光照先使用基础日光，新增静态几何具备GI/UV，统一实际烘焙及剔除在五区几何完成后W06-B实施并独立报告，当前不称Lightmap已通过。山谷没有局部体积雾。
