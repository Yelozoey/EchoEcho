# S2 D03 脚本命令识别

D02独立通过后实施。仅手工规则和目标别名，不导入模型、不承诺理解任意自然语言。输出为已有六种IntentRequest或待回答的问题/澄清状态，所有行动仍须经D04的现有IntentDispatcher；识别层不访问GameObject。

支持预设follow/跟随我/跟着我，wait/等待/等在这里/原地待命，调查/扫描/去调查/去扫描加目标名或唯一ID，warn/警告加危险目标及“附近有危险吗”。支持Echo称呼、请和首尾标点；否定句不套用肯定指令。多行动请求要求拆成一次一个行动，不默认先做其中之一。

目标描述只含ID、显示名、手工别名和可调查/危险标志；由D04传入当前可用目标集合，不遍历隐蔽世界资产。精确ID/全名/别名优先，无法唯一确定时列出候选，未确认不执行。当前澄清可接受后续目标全名/ID，新的明确指令可替代旧澄清；最终会话代次控制在D04。

“给我提示/下一步”映射Hint问题，“整理线索/我们知道什么”映射Summary，“密码”信息问题映射Password，其余明确问句映射Fact；本模块不生成未开发的知识回答。帮我/替我操作门、设备、输入密码、改回路等命令输出refuse；询问密码或操作方法仍作为信息问题。未知输入使用规定的理解失败短句，不执行外部JSON或代码。

普通参数：原始输入最多200字符，Unicode FormKC/小写/首尾空白与标点归一；目标最多128个、稳定ID唯一、显示名80字符、每目标最多16个手工别名。澄清台词最多展示前三个名字并限制280字符，其余仍可用唯一ID指定。

独立用例：跟随/等待同义词及标点、调查ID/全名/别名、模糊候选与后续明确选择、无目标/非法目标、危险类型、answer问题分类、禁止动作与密码问句区分、否定/多动作、未知/代码字符串、输入/catalog边界和外部数组隔离。2026-10-25独立12/12通过，见[报告](../Tests/Stage2/Reports/S2-D03_ScriptCommands_TestReport.md)，证据Evidence/S2-D03，进入D04。
