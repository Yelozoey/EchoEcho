# S2 D05 已知事实回答与三级提示

D04独立通过后实现纯数据回答器。输入为已确认的Question类型、当前MemorySession和手工检索目录；输出只能answer/refuse，不产生动作，不访问GameObject。D04仍负责记忆桥就绪和意图权限。

事实/摘要只从M06筛选结果取完整简述，最多3条且合计≤280字符；无相关记录使用“我目前没有相关记录。”。摘要问题用线索/记录/资料检索词，仍≤8条/1200 UTF-8字节；不读取玩家全文或整段对话历史。显式Password问题才可复述已知ClueMemory.Password；有多条不同密码且相关度不唯一时澄清，禁止猜测。其他回答和Hint统一遮蔽配置的密码值，防止摘要或提示模板意外泄露。

HintPlan是D06后续内容数据：唯一ID、可选当前区域、必要的已知事实、完成事件、检索主题和恰好三级短句。只有当前区域匹配、全部事实已知且尚未完成时才可选；无合格计划只给泛化阅读建议。三级随明确索要提示递进，第三级保持；不改谜题状态。会话或记忆版本变化重置级别。区域仅从角色记忆player_current_zone的TargetId读取，不直接查场景。

普通数据边界：最多64个提示计划，每计划最多8个必要事实，每级1–280字符，检索词最多200字符；配置数组复制/只读，密码遮蔽表最多16个短值。记忆中已知密码同样加入遮蔽。完整六谜题的具体计划/台词在D06建立并独立验证，不提前把测试用例当产品剧本。

用例：未知信息不泄露、显式已知密码、非显式遮蔽、密码歧义、三层/区域/必要事实、完成后停止、换代重置、上下文/回复预算、无状态操作/原文、外部数组隔离及非法配置。2026-10-25独立11/11通过，见[报告](../Tests/Stage2/Reports/S2-D05_KnownAnswers_TestReport.md)，证据Evidence/S2-D05，进入D06完整内容配置。
