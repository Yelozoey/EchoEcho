# S2 W04 地下A灰盒

12×16米实验室位于地面下4米，南接3.2米下降通路、北接5米通风通道。净高4米，两侧墙体/顶棚/有门洞端墙界定房间。四份来源依已确认设计布置：回路说明(-4.8,-2.75,25)、维护指令(-3.5,-2.75,34.5)、隐藏校准架(4.4,-2.6,33)、传感器便签(2.5,-2.75,25)。面板设备位于(-4.5,-2.7,28.8)，只能由玩家在P03切换。

北入口通路初始物理隔离，由P03正确供电并真实雾消退后开放；这里先验证碰撞/导航、实际线索阅读、真实扫描和A区码仅扫描后入库。局部体积采样在P03独立实现与图像/GPU验证，不能用当前边界隔离方块替代体积雾。统一光照烘焙在W06-B。
