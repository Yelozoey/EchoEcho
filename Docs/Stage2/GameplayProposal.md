# 阶段 2 五区谜题与三个结局设计提案

版本 0.1，2026-10-25，用户已确认完整玩法、对话及工程方案，并授权逐模块连续推进 S2。确认原话和边界见 [连续执行记录](ContinuousExecutionAuthorization.md)；剧情、密码、回路和结局仍需按模块实施与测试。

## 玩家目标与事故背景

玩家作为返站复查人员进入已撤离的生态观测站，寻找异常停站原因，决定如何处置剩余监测系统和事故记录。Echo 是遗留科研助理，记录不完整，只能依据已发现事实提供信息。

事故起于实验室局部排风传感器校准偏差。维护时误将实验支路接入内循环，异常空气回流，触发停站；人员主动撤离并断开危险实验支路。记录中的断电发生在报警之后，属于控制后果。完整证据还能证明：低功耗生态监测与危险实验支路可以分离运行。

以无人环境和故障设备制造压力，无战斗、无追逐敌人、无生命倒计时。台词及文档保持科研用语和克制语气；不新增信任数值、道德积分或随机结局。

## 六个谜题与区域分布

六个实例分别占用四种已规定类型，五区分布为 1/1/2/1/1。隐藏标记在小屋的首次扫描是第四个谜题的跨区线索，不另计第七个谜题。

| 实例 | 区域与类型 | 玩家要做的事 | 完成结果 |
| --- | --- | --- | --- |
| S2-PZ01 时间线互证 | 山谷，笔记线索拼图 | 收集入口巡检记录和撤离通知，在日志核对两者时间；确认报警先于人工断电 | 形成“断电不是起因”的证据，属于可选调查，不锁死进入小屋 |
| S2-PZ02 小屋维护终端 | 小屋，终端密码 | 在维护记录中找到服务码 **7316**，亲自在终端输入 | 获得地下区域访问授权及维护记录；玩家再 E 操作地下通路门 |
| S2-PZ03 通风供电 | 地下 A，供电回路 | 阅读回路说明，设置三个标记清楚的开关：**排风 ON、内循环 OFF、实验支路 OFF**，再由玩家按确认送电 | 通风恢复，通道入口局部体积雾在 3 秒内消退；玩家可进入通风通道 |
| S2-PZ04 校准标记 | 小屋至地下 A，Echo 专属扫描 | 请 Echo 扫描小屋储藏室可疑点；显现的标记指向 A 区校准架。再请 Echo 到 A 区扫描对应隐藏标记 | 日志得到维护校准凭证和通道终端码 **0428**；仅记录信息，不自动解锁设备 |
| S2-PZ05 通道维护终端 | 通风通道，终端密码 | 在已有真实 Echo 校准凭证后，玩家输入 **0428** | 核心通路可由玩家 E 打开，并取得通道维护记录 |
| S2-PZ06 事故归档互证 | 核心控制室，笔记线索拼图 | 将 A 区维护指令、通道维护记录和核心传感器时序三篇资料对照，在日志确认结论 | 证实校准偏差与回流原因，并确认低功耗监测可以独立保留；属于可选完整调查 |

笔记核对只产生信息与证据状态，不自行改变门或机关。终端密码输入正确不等于收集过密码来源；Echo 仍不能凭解锁状态假装读过笔记。小屋终端允许玩家猜中密码，通道终端额外要求实际获得校准凭证，保证 Echo 扫描在流程中有必要用途。

供电回路没有随机答案和惩罚性重置。错误组合只显示“当前回路不满足通风条件”，保持不可通行；不会伤害玩家、扣除道具或永久锁死。正确送电后该谜题锁定为已完成，重复交互显示当前状态，避免读档或误操作把玩家困在另一侧。

## 从小屋蓝色方块到下一步

S1 的 `scan_mark_01` 继续作为小屋可疑点 ID。S2 扫描成功后，标记以简洁图形指向 A 区校准架，日志新增具体目标，Echo 说明：“标记指向地下 A 区校准架。我可以在那里复核。”

若玩家尚未开地下通路，提示先查看小屋维护记录和终端；若已有授权，提示地下入口方向。到 A 区后只有真实扫描通过才记录第二个标记和凭证。玩家必须自己操作终端和回路，Echo 没有对应写入入口。

## 三个结局

三个结局均由核心终端的玩家明确选择触发。没有隐藏自动结局或对话措辞判分；选择前显示后果并要求一次确认。条件不足的选项显示缺少证据的提示，允许返回调查。取消确认返回游戏，不消费任何物品。

| 结局 | 条件 | 玩家选择与结果 |
| --- | --- | --- |
| 封存撤离 | 主通路谜题 PZ02/PZ03/PZ04/PZ05 已完成 | 切断剩余站内供电并封存现场，保留当前收集记录后撤离；Echo 跟随玩家 |
| 保留监测 | 主通路完成，且 PZ06 完成 | 玩家选择保持实验支路隔离，仅保留低功耗生态监测；Echo 在已明确指令下留站值守 |
| 完整归档 | 主通路完成，且 PZ01 与 PZ06 都完成 | 玩家将完整证据归档至本地随身存储，确认实验支路隔离后撤离；Echo 携带完整维护摘要跟随玩家 |

“归档”是游戏内本地状态和结局展示，不发网络请求、不写真实外部设备。结局不依赖 LLM、性能档或随机事件。结局后可返回标题、开始新局或读取结局选择前的手动存档；不自动覆盖该存档，不提供未制作的开放世界后日谈。

## 主路径与可选调查

主路径：山谷进入小屋 → PZ02 授权 → 玩家开门下到 A 区 → PZ03 供电 → PZ04 凭证 → PZ05 开核心通路 → 核心选择“封存撤离”。PZ04 可先后分段完成；其小屋扫描在进 A 区前有明确提示，遗漏后仍允许沿原路返回。

完整调查在山谷完成 PZ01，并在核心完成 PZ06，才能选择“完整归档”。只完成 PZ06 则额外开放“保留监测”。解锁条件分别测试，三个结果互斥；不会因先满足某个条件就自动抢占选择。

目标首次游玩 25–40 分钟，计划分配山谷 3–5、小屋 5–7、地下 A 7–11、通道 4–6、核心 6–9 分钟。文档总量暂定 14 篇，每篇约 120–240 中文字符，全文与摘要独立编写。实际时长须由完整路线实测；若不足，调整这六个谜题的线索表达和探索距离，不新增谜题类型或强制等待来凑时长。

## 脚本对话建议

- uGUI 复用随包 Noto 字体。T 打开对话、Enter 提交、Esc 关闭；J 日志和 Tab 控制面板与对话互斥，输入时不触发移动、交互或快捷命令。保留 Tab 的确定性按钮作为脚本操作入口。
- 单次输入最多 200 个 C# 字符，空白不提交；Echo 回复最多 280 字符，与现有意图校验一致。面板保留最近 100 条消息，存档保留最近 50 条；对话原文只供 UI，不作为记忆检索上下文。
- 支持预先列出的中文命令及同义词，例如“跟随我”“等在这里”“调查储藏室可疑点”“扫描供电面板”“附近有危险吗”“整理线索”“给我提示”。通过命令词和明确目标映射到六种现有意图；多个候选目标时列出选择，不自行猜测。面板列出可用例句，避免暗示脚本系统能理解任意自然语言。
- 未知命令回复“抱歉，我没能理解你的指令，请换一种说法。”；未知事实回复“我目前没有相关记录。”；替玩家开门/改回路的请求走 refuse。
- 提示按“应调查的方向 → 已知线索间关系 → 玩家明确追问后复述已收集的关键事实”三级推进。未知资料不泄露，已知密码只有玩家明确询问时才复述；所有输入和操作仍由玩家完成。

## 工程方案建议

| 项目 | 建议与验收 |
| --- | --- |
| 记忆 JSON | 复用项目已安装的 Json.NET，不升级依赖；独立 DTO、严格字段/枚举/缺失/重复字段校验、版本和校验。M01 无引擎依赖保持；反序列化只能生成已校验记录 |
| 持久化 | S2 使用独立 `Saves/S2/slot1.json`，不迁移或覆盖 S1；最终一次原子提交同时保存进度、日志 ID、扫描、记忆和 UI 历史。单文件 UTF-8 上限 2MiB，超限拒绝并保留旧档；备份/损坏/未来版本保护沿用 S1 原则。M03 只在隔离目录验证文件组件，F03 再整合全状态 |
| 保存时机 | 沿用 F5 手动保存、F9 读取；不自动载入、不退出时覆盖。读取前整体校验，失败不部分改变游戏；新局清空全部 S2 运行时进度和记忆 |
| 灰盒加载 | S2 建一张专用五区灰盒场景，五区以可步行通路连通；不修改 S1 场景/构建。S4 再拆分为 Addressables 距离流送区块，不把 S2 单场景写成流送已完成 |
| Echo 跨区 | 共用同一专用 Agent 类型和连续 NavMesh，沿路跟随；保留既有真实扫描/遮挡与避让。卡住只提示并允许玩家重新下达调查，不瞬移穿门；若后续需要召回机制另行确认 |
| 灰盒光照 | 复用已验收普通 Forward/HDR/SDR/D3D11 模板，逐区静态烘焙、按室合并和 PVS；动态物体 SRP Batcher。先用简单原生几何，不额外引入植被/碎石资源 |
| 局部体积雾 | 自定义 URP Renderer Feature，在 A 区/通道边界内沿视线进行真实体积采样并由场景深度遮挡；初始半分辨率、每射线 16 步、最多 2 个局部光体积。山谷关闭；供电改变通道局部密度。普通距离雾不算通过；独立截图与 GPU 对照后再整合 |
| 测试与构建 | 逐模块独立报告后推进；必要的可见 Windows 测试窗口、截图、真实 Profiler 和隔离存档验证属于 S2 验收。只有所有场景/Prefab 干净时才进入可能切换状态的操作，不保存/丢弃用户改动；本提案不要求重启 Unity |

确认本表后，普通实现细节及性能数值调优拟由代理先记录再实施；超出本表、改变谜题/结局、修改硬约束或需要新的剧情内容决定时继续询问。确认不放宽逐模块独立测试门禁，也不等于目标硬件验收已通过。

## 需要独立验证的路线

1. 最短合法主路径可以到“封存撤离”，Echo 全程只提供信息。
2. 主路径加 PZ06 可到“保留监测”，未做 PZ01 时“完整归档”不可选。
3. PZ01/PZ06 加主路径可到“完整归档”，所有证据和显示文字一致。
4. 猜中小屋密码不伪造已读线索；猜中通道密码但没有真实扫描凭证不能绕过 PZ04。
5. 错误密码、错误回路、漏读笔记、乱序扫描、重复操作、返回前区和中途读档不会永久锁死。
6. 新进度不能搭配旧记忆；读档不重复触发发现，损坏档不部分改变门、供电或 Echo。
7. 本地断网运行全流程和三个结局；没有模型、网络对话、语音或额外谜题系统依赖。

本方案已按S2的30个工程模块逐项实现并测试归档，见Docs/Tests/Stage2/Index.md。正式目标硬件/首次体验时长仍待外部验收；保留v0.1作为批准的设计依据。
