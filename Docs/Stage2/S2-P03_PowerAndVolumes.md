# S2 P03 通风供电与真实局部体积

继续拆为A纯回路/三秒状态测试，B独立URP局部体积实现与图像验证，C玩家面板与通路联动，D可见Windows GPU对照。A通过才B，B通过才C，C通过才D；每步报告。没有普通距离雾代替采样。

A：待提交的三个开关初始为排风OFF/内循环ON/实验支路ON，表示面板选择并非实际送电；玩家确认前设备不执行。只有排风ON/内循环OFF/实验OFF才能提交；须PZ02，错误无惩罚可重试，成功保持且不可重新切断。通风效果3秒消退、结束才开放通路；恢复中存档需保留0–3秒进度，不能困住两侧。

B：复制Gameplay普通Forward/HDR为S2专用Pipeline/Renderer，保留S1原件；增局部体积Feature。A区AABB(-6,-4,22)至(6,0,38)、通道(-2.5,-4,38)至(2.5,0,58)，视线与场景深度截断、半分辨率16次积分、两个局部光散射。初始密度.025/.17，成功后3秒降至.008/.015。只在相应局部空间着色，山谷跳过；体积颜色冷蓝灰，局部灯增强可独立对照。使用RenderGraph临时纹理，不生成大量粒子。

C：E查看供电面板，三选择开关+确认/取消；只有玩家交互写回路，Echo仅扫描说明。面板模态阻止移动和其他UI、Esc/失焦关闭；正确提交后3秒实际雾消退，再取消Vent_Isolation碰撞/导航障碍。D在1080p/D3D11可见测试窗口获取有效GPU样本，记录效果开/关中位数和P95及图像，开发机不代替目标硬件60FPS证明。

渲染门禁保持所有原有要求，只在原两条路径外增加唯一明确的S2专用资产路径Assets/EchoStation/Station/Generated/ES_S2_ForwardHDR.asset，不允许任意管线。普通Forward/HDR/SDR/PC/D3D11及三绑定相同仍强制检查。
