# S1-E09 待命子树与独立测试计划

2026-10-25，前置E08整体81/81及六项审计通过。wait只原地待命，不新增行为模式、扫描动作或玩家输入。

进入通过当前MovementLease停止并清路径；持续Running保持wait，目标移动不会触发跟随。若底层意外仍Moving，再次停止；退出仍清理本代次，旧代次不能控制新行为。E08仅follow自主扫描，因此绑定真实根模式后wait会取消未完成自动扫描。
