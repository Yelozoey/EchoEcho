# S1-P06 交互目标对焦景深

2026-10-25连续S1授权，P05通过后实施。A有界焦点/渐入渐出状态→B项目专用Volume/玩家接线及实际深度图像→C Windows效果/Overlay清晰/开销诊断，逐项归档后进入P07。

使用URP17.6原生Bokeh景深，50mm、f/5.6、5叶片/曲率1/旋转0。相机中心选中合法交互目标时按实际射线命中距离对焦，距离约束.35–2.5m；首次激活立即定焦再.15s渐入，目标改变以10/s指数平滑；无目标/遮挡/失焦/UI时.15s渐出，低于.001关闭实际景深贡献。不锁定已失效目标，不改变Player/Echo行为。

新建只有DepthOfField的ES_Volume_InteractionFocus及ES_InteractionFocusVolume，层8/全局/priority20；保留R02原Volume/Profile资产，镜头内部HDR/SDR与普通Forward/D3D11不变。运行期仅实例化自身Profile一次，禁用/销毁清理，玩家相机明确请求深度。Overlay提示/日志在后处理之后，不被景深模糊。

A检查近/远限幅、平滑/退出、无效输入/重置。B在隔离渲染层/灯光条件下用近远不同深度图案，量化近处保持清晰、背景边缘对比下降、焦点/遮挡/UI切换，FrameDebugger确认原生Bokeh路径；测试夹具关闭颗粒等随机干扰只改实例。C Windows必须验证Bokeh Shader保留与实际效果，不能以F019禁用剥离警告绕过。当前机开关普通帧CPU/GPU是诊断，目标最低/推荐配置60FPS仍需实机。

诊断构建如需临时Gameplay管线变体，恢复时按已记录资产路径重新加载并核对前后RenderSafety，不能给默认/Quality写入null；13份保护SHA保持。此模块不制作高/中/低完整画质预设，仍在S4。

实现细节：使用.15s状态权重将物理光圈32→5.6渐变；Volume在有效权重时为1，无效时0。避免用非插值模式字段的混合冒充线性模糊渐变。
