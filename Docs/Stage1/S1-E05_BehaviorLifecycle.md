# S1-E05 行为树根与移动控制权、独立测试计划

2026-10-25，前置E04六项通过。只开发四意图根切换、节点Enter/Tick/Exit、完成/失败/取消和移动授权代次；具体follow/investigate/wait/warn子树分别在E06/E07/E09/E10，不用空壳冒充具体行为已完成。

根通过注册工厂创建对应子树，执行单节点生命周期；仅接受E04验证后的BehaviorIntent。切换先退出旧树并停止/撤销其移动控制权，再进入新树，任意时刻只有当前代次可发送移动/停止。旧协程晚到请求被拒绝，不能改新树路径。取消/完成/失败/禁用撤销并清路径，重复取消幂等。answer/refuse由Dispatcher发消息，不切树。

节点返回Running/Success/Failure；工厂缺失/返回null时拒绝并保留旧行为，Enter/Tick/Exit异常清理授权/停止并记录错误供调用者检查，不让错误节点继续控制移动。同步Unity主线程Tick驱动，未引入LLM线程。

独立测试：follow→investigate→wait→warn顺序与单一进入/退出；切换后旧Tick不执行、旧代次迟到移动/停止无效；取消幂等、成功/失败都清路径；输入未注册子树保持旧行为；Enter/Tick/Exit异常安全撤销；answer/refuse保持当前行为。使用可计数的测试子树/移动端口验证，E05不实例化产品机器人或提前实现玩家。
