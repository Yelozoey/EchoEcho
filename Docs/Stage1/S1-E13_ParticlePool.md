# S1-E13 粒子池与全局预算

2026-10-25连续授权的普通参数决策，E12验收后实施。当前产品不需要粒子，不额外增加产品效果；本模块交付可用的预算/池运行组件及独立粒子测试夹具。

A：固定容量预热池，单池1–4；全局最大并发4个系统，每系统最多64粒子，总理论上限256。只接受单个非循环ParticleSystem，禁止子粒子/子发射器/PlayOnAwake/自动Destroy，防止绕过预算或池。请求不扩容、不Instantiate；池满或全局满直接拒绝，返回代次租约防止过期请求停止新效果。禁用/销毁清理预算，后续重启可复用池。

B：真实播放上限+1、两个池争用全局预算、自然结束回收、主动取消/旧租约、禁用恢复及重复压力请求，核对实际粒子数和对象数不增长。通过后留档；产品Prefab/场景仍无粒子。后续增加产品粒子必须经此池/预算且单独验收。
