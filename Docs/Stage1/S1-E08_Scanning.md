# S1-E08 Echo扫描拆分与测试计划

2026-10-25，前置E07策略6/6、实际5目标1/1通过。本模块拆为A数据权限/幂等 → B实际扫描器的距离/视线/探头和时序 → C调查后扫描/自主扫描整合，每项独立报告后推进。

A：ClueSource的揭示方法保持internal，World程序集只向Echo.Runtime开放；正式玩家程序集无揭示接口，仍只TryRead。Echo内部账本提交经显式调查能力验证的目标，扫描结果只包含目标ID/摘要/隐藏类型/本次是否新发现，不含全文。每目标只发一次发现事件；重复扫描可返回摘要但不重复归档。4份Clue数据沿用W04；供电面板仅使用<=120字符的信息摘要，不改机关状态。A数据测试会直接调用Echo内部提交，不冒充真实传感器已经完成。

B：真实EchoRig+ScanOrigin才可启动，范围2.2m；指定扫描可转探头对准目标，俯仰限制±50度，水平可环转；物理视线不能穿墙，命中目标自己的Collider允许。有效对准后持续.6游戏秒，完成前再次核验距离/视线/目标权限，才提交账本。取消/失效不揭示；提交后1秒冷却。返回普通台词与状态事件，不引入语音/LLM/粒子。具体实现与实测参数在B报告记录。

C：复用E07到位子树后执行扫描，切换/取消会撤销进行中的扫描；跟随过程可对附近合法线索自主扫描，扫描只提供信息，不自动移动开门或修改谜题状态。隐藏扫描标记显现/扫描摘要事件/重复扫描幂等必须由实际Scanner证据验收。全屏波纹特效在E12，动画绑定在E11，不能拿状态字段宣称两者已完成。

C1实际射线暴露桌面遮挡维护笔记（F-050）；临时纸片移到桌前侧(-2.8,.8,1.885)、X旋转90度。ID/文本/批准点和静态桌子保持，不忽略桌子碰撞；这项普通原型摆放修正按连续授权执行并留存失败证据。

C2自主策略：只有明确绑定follow模式且机器人当前不在移动时，每.5秒做一次32个Collider预算的2.2m近邻查询，选择最近、物理合法、尚未记录的线索/信息目标；不为扫描发移动命令。离开follow仅取消本组件拥有的自动扫描代次，不干扰新的手动扫描。未绑定模式默认关闭，wait不自主扫描。实际意图绑定在P09完成，C2独立夹具直接驱动该模式通道，不宣称wait子树已经实现。

独立用例：A无公开揭示入口、未扫描TryRead=false、有效内部提交后可读/显示、重复事件一次、摘要与全文分离、无权/停用/坏数据不揭示；B非Echo/超距/墙后/目标失效/取消/冷却/实际探头对准，C实际五目标调查扫描、隐藏显现且所有机关Transform/状态保持。若视线暴露灰盒摆放问题，留存失败证据并修正临时摆放后重测，不放宽穿墙限制。
