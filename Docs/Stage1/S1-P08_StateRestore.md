# S1-P08 状态恢复适配

连续授权范围：A规范恢复数据/信任边界与实际非法状态拒绝；B真实小屋收集/扫描→磁盘保存→卸载重新载入→读取恢复，及旧存档回滚/去重/设备保持；通过后再P09。

存档只保存ID，读取当前项目规范数据重建完整日志，顺序保持，不信任文件中的自定义台词或原文。扫描ID必须对应当前场景可调查目标且已归档；隐藏日志必须有扫描授权。位置先检查当前场景地面/碰撞及Echo NavMesh和机身净空，非法不部分应用。恢复取消在途行为/扫描、清垂直速度、恢复yaw/pitch/手电，Echo以follow或wait重建行为树，调查/warn存档落为wait。读取后释放鼠标，需要新点击。

只有持久化适配器程序集可调用内部恢复桥，LLM/意图入口没有显现或清空接口；正常扫描传感器门禁不变。恢复已有授权扫描显现隐藏标记，恢复旧存档可再次隐藏；不动门/供电设备。读取不发重复收集事件，UI一次刷新，未接S2记忆/对话。
