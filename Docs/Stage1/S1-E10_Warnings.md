# S1-E10 感知、警告与脚本NPC接线拆分

2026-10-25，前置E09三项通过；A危险感知 → B warn子树 → C传统Echo控制器，各自独立测试/报告后推进。

A：距离4m（边界含）、机身前向半角55度，视线起点ScanOrigin，实际物理遮挡、目标自身Collider允许/自身机器人Collider忽略；只识别显式IsDanger且激活的WorldTarget。不因探头思考/扫描转向改变机身感知角度。每次近邻32 Collider/射线16命中预算，过载保守拒绝，不依赖名字推断危险。测试距离内/边界/外、视角内/边界/外、真实墙、危险能力/停用、最近合法目标。

B：warn进入先停止，本地目标仍有效且有危险能力才持续警告；保持1.5游戏秒后完成，期间不移动/开门/改设备。台词走E04 content，冷静简短。测试进入/保持/结束、目标失效、没有移动命令，之后实际控制器统一接线。

C：EchoBrain显式初始化后组合已验收follow/investigate+scan/wait/warn，正常Mono Update驱动，未初始化的模型/导航夹具不自动运行。危险每.2秒感知，同一目标8秒告警冷却；自动告警临时中断当前行为并停止，结束后仅在用户未发新行为指令时恢复此前行为。新的有效用户行为取消待恢复记录，不能在wait后偷偷恢复旧follow。answer/refuse不改变行为。手动警告需当前可感知的合法危险，结束进入wait；调查完成进入wait。

冷却明确仅限制自动提示：手动有效warn允许重复，但每次都会重置该目标的8秒自动冷却，避免手动刚警告完又被自动提示重复打断。额外实际边界测试验证满8秒后才可自动再次警告；同冷却过滤不能遮蔽其他可见危险目标。

扫描自主模式绑定实际行为根；无LLM提供器，GameRuntimeOptions.UseLLM保持S1默认false。仅信息/扫描/警告，无机制操作接口。C独立实际小屋验证自动警告/冷却/恢复、告警中用户wait覆盖、六意图和四子树接线；正式玩家、UI与存档留对应P模块。参数由连续授权委托代理决定，最终执行证据记录实际值。
