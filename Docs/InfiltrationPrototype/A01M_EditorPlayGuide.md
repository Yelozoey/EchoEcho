# A01-M 金属材质大场景 Editor 试玩

场景：`Assets/EchoStation/InfiltrationMetal/Scenes/ES_Infiltration_Metal.unity`。在Unity打开后按Play，点击Game；本项完成后停在Edit，留给本人主动开始。旧精修版与反射小样仍保留。

WASD移动，鼠标转向，Space跳跃；Esc释放鼠标，再点Game恢复控制。Tab隐藏/显示路线，F8关闭/开启中庭地面实时倒影。

建议先观察入口墙面、检查台外壳和门框，侧向移动看宽而模糊的金属反光；沿蓝线进入中庭，低头看中央4×4m金属地面，按F8比较机器人、灯条和门口的倒影。再绕行政与检修路线，比较终端少量抛光边框与粗糙设备壳。原屏幕、玻璃、标识、灯面、黑色非金属与布料保留各自材质，不能以它们没有金属反射判定漏改。

墙面/外壳采用粗糙金属，光泽由原法线/色图、新金属粗糙度遮罩、重烘焙与区域探针共同产生。曲面/墙面不会呈现实时镜像；中庭一块地面用平面反射提供清晰实时倒影，属于PBR＋探针＋局部平面反射，非硬件光追/SSR。F8只影响地面实时倒影，粗糙金属仍有探针和灯光高光。

保留六区/三条主路/双回环、78装饰及四守卫岗位；机器人仍只展示Idle，本项没有潜入规则、真实巡逻或Echo LLM，不能把视觉样板当可通关游戏。

请重点反馈：墙面/设备的金属感是否合适，是否过暗或过亮，终端亮边是否抢眼，中庭局部倒影是否自然。工程测试与本机Editor开销见`Docs/Tests/InfiltrationPrototype/Reports/A01-M03_Editor_TestReport.md`；目标基准机60FPS尚未验收。
