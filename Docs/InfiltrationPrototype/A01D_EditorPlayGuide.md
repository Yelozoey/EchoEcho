# A01-D 精修场景：Editor走图

打开Assets/EchoStation/InfiltrationRefinement/Scenes/ES_Infiltration_Dressed.unity，按Play后点击Game。WASD移动、鼠标转头、空格跳跃；Esc释放鼠标，再点击Game恢复；Tab隐藏/显示路线线条。退出Play即可，不需保存Play中的改动。

本轮补78件静态装饰、50个独立发光面、中庭顶窗格栅与重烘焙/区域反射；仍为六区三路双回环的美术样板。四机器人仅岗位展示和Idle，黄线是巡逻预览；Echo静态展示。尚无凭证检查、巡逻/追赶、胜败、任务拿取或LLM通信。

建议走3–5分钟：

1. 接待处先看左右座椅/柜子/桌面和三路入口，抬头检查灯具发光面；沿正面蓝线进中庭，观察顶窗格栅的光影与门岗轮廓。
2. 左转行政，走近杯子、终端、柜架；转入西检修，抬头看贴墙线槽、风机和通风口，再沿后横廊透过窗口观察核心。
3. 绕到东检修和仓区，检查货架、覆盖布箱、桶及门洞通行；回接待后按Tab关辅助线，再试找核心和退路。

重点反馈：装饰是否有用途且不显拥挤；灯面是否刺眼、暗处是否可读；中庭顶光与办公室/仓区的差别是否自然。可按“区域→对象/朝向→问题”描述。自动非黑图测试不代表你已接受美术。

36×32m、净地面保守下界1007.7m²，常规4.5m/中庭6m；未缩小地图。保留A01原场景ES_Infiltration_Routes可回看。本场景Play期间使用自有DR Forward/HDR资产，退出还原进入前绑定；HDR仅内部渲染、SDR显示。SSAO、烘焙GI、区域反射与有限主光阴影薄雾已有实际证据；SSR/SSS未新增。
