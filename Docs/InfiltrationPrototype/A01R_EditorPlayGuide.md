# 金属与实时反射小样

场景：Assets/EchoStation/ReflectionSample/Scenes/ES_ReflectionSample.unity。Play后点击Game，WASD/鼠标移动观察，空格跳跃、Esc释放鼠标。此场景独立展示反射，不是潜入任务；原大地图完整保留。

先看后排三个球：左为粗糙金属，中为抛光金属，右为原场景涂装材质。中间球主要显示灯光高光与静态环境反射；金属并不都像镜子，涂装/粗糙度会改变反射形态。

再稍向下看中央黑色金属地面，观察机器人、彩色箱体和灯条的倒影，侧移/转头检查倒影随视角变化。机器人只做演示往返移动，不是新增守卫AI。

| 按键 | 对照内容 |
| --- | --- |
| 1 | 中央地面实时倒影开/关，关闭后回退探针 |
| 2 | 球体等Lit材质的环境反射开/关 |
| 3 | Lit材质的直接光照高光开/关 |
| P | 暂停/恢复机器人演示移动，便于固定姿态比较 |

建议先P暂停，再1开关两次；之后2、3分别开关，观察抛光球。退出Play即可。左上角说明当前状态，地面的平面反射与球体的探针是不同技术。

这是PBR＋512静态探针＋单块1024宽实时平面反射，**非硬件光追/SSR**；曲面没有套平面倒影，不承诺任意物体全场景实时互相反射。仍Unity6000.6.7f1、普通Forward、内部HDR/SDR、D3D11。尚未铺回大地图、没有目标机60FPS验收。
