# 反馈02首次试玩记录表（待真实玩家填写）

用途：检查新空间高度、三区识别、HUD与Echo协作是否易懂。本文件是执行材料，不是已通过的外部试玩结果。

建议找3–5名没有玩过本项目的人，逐人独立试玩。主持人先记录版本/机器/画质/分辨率，只说“探索设施，搬运物品回泊位，尝试使用Echo，完成一次回收任务”；前两分钟尽量不讲路线和按钮答案。卡住时先询问其想做什么，再逐条记录提示内容与时刻。允许随时结束，不把自动测试时长当首次玩家时长。

## 试玩后提问

1. 进入游戏后，你以为应该先做什么？实际哪里让你停下来？
2. 场景高度是否仍压抑？哪个房间最难辨认，哪里太暗或太亮？
3. 能否不看说明说出三个区的区别、泊位在哪里、返回路线在哪里？
4. HUD中哪些信息你真正用过？哪些看不清、看不懂或挡住视野？请同时记录分辨率。
5. Echo哪一次帮助了你？扫描后你以为会发生什么？是否误认为它可以搬运或打开设备？
6. 拿起/放下/确认交付、任务板结算的哪个步骤不明显？
7. 如果还想继续玩，最想保留/改善的一件事是什么？
