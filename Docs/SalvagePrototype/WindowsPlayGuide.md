# 回收探索 Windows试玩说明

第一次游玩请先看[从出生点到结算的新手引导](NewPlayerGuide.md)，其中包含一条明确的三件物品完成路线。

2026-10-31空间/HUD反馈版：泊位与储藏区层高4.5m、检修间5m；新增三区高位地标/区标、重烘焙灯光与流送/PVS，HUD与任务板重新排版。玩法与按键保持一致，旧亮度版完整归档。新入口为ArtV2/ES_ArtV2_Streamed.unity。

双击发行目录内的`EchoStationSalvageNext.exe`启动（项目路径：`Builds/SalvageNext`），保持同目录的`_Data`文件夹和DLL完整。新版采用独立场景/存档，旧R2和五区解谜版保留。当前为脚本Echo；本地模型有界测试未过质量门禁，UseLLM关闭，设置界面不可绕过门禁。

目标：带回至少3件物品且累计至少12分，返回泊位主动确认结算。三区是回收泊位、储藏区、检修间，有上下两条连接与返回短路。无需文字输入也能完成。

| 操作 | 按键/入口 |
| --- | --- |
| 移动、视角、跳跃 | WASD、鼠标、空格 |
| 手电筒 | F |
| 拾取/泊位请求交付 | 对准物品或到泊位后 E；交付需再次确认 |
| 放下单件物品 | G；安全落点才可放下，不能投掷 |
| Echo面板 | R；调查准星或已发现目标、跟随、待命、取消 |
| 可选文字通信 | T；200字上限，支持脚本命令/问电量 |
| 回收建议 | R内就近/高分/轻量，建议后再确认一个目标 |
| 任务板与主动结算 | Tab；达到目标不会自动结束 |
| 新版独立存档/读档 | F5 / F9；设置面板中暂不响应 |
| 画质/分辨率/窗口模式 | F10或右上设置按钮；应用后15秒内确认 |
| 释放鼠标/关闭面板 | Esc；点击游戏区域重新捕获鼠标 |

物品A–F重量/分数分别为2kg/2、4kg/4、2kg/3、6kg/6、8kg/8、4kg/5；另有12kg超重件不能搬运。单件手持上限8kg，越重移动越慢。一条可达标路线是A+B+D，另一条是C+F+B；这些是试玩提示，不是强制顺序。

Echo可前往扫描、整理短摘要、标记与警告，不能搬运、自动开门或改变设备。首次成功新扫描扣8电，重复/失败/取消不重复收费；泊位可充电，空电仍可低速跟随。橙色配电设备/泄漏管段仅提供只读警告，不伤害玩家。扫描标记用于信息协作，不是打开机关的步骤。

发出调查指令后给Echo留出门口和目标附近的位置；玩家占住狭窄通道时，机器人可能报告目标不可达，此时让开后重新指令即可。

进度位于`persistentDataPath/SalvageNext/slot1.json`，显示配置位于同目录`settings.json`，都有独立备份；不会覆盖R2槽。读档保留已发现信息、文字记录与基础模式，取消进行中的任务。试玩构建与验证记录以最终交付报告为准。

本轮性能基准是Windows10/11 x64、D3D11、1920×1080、URP普通Forward、内部HDR转SDR。开发机测试不等于i5-8400/GTX1060最低配置或i5-12400/RTX3060推荐配置达标，尚需对应硬件复测；首次外部试玩记录表已准备，尚无真实玩家结果；求职材料制作未开始。

HUD左上是回收目标与区域，左下是Echo模式/电量，右下是手持重量/价值，准星旁只在可交互时显示提示。Tab任务板分别列出待回收、手持、已交付和超限状态。
