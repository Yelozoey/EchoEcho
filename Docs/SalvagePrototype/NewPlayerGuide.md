# 第一次回收：新手引导

适用：2026-10-31 空间/HUD反馈版，Windows程序 `Builds/SalvageNext/EchoStationSalvageNext.exe`。这是可对照游玩的文字引导。

你要做的事是：探索房间，把物品亲手搬回回收泊位，交付至少 **3件**、累计至少 **12分**，然后主动结束任务。Echo负责调查和提供信息，搬运由你完成。全程可以不打字。

## 1. 启动并认清出发点

双击 `EchoStationSalvageNext.exe`。如果鼠标没有控制视角，点击游戏画面。

出生点在“01 回收泊位”。先记住脚下附近的蓝色地面回收区，之后每拿一件物品都要回到这里。三个区依次是：回收泊位 ↔ 储藏区 ↔ 检修间；从门洞通行。

- WASD移动，鼠标转头，空格跳跃；F开关手电。
- 左上角：已交付件数、分数和所在区域。
- 左下角：Echo状态和电量。
- 右下角：当前手持物品及其重量、价值。
- Tab打开任务板，Esc返回。

## 2. 先拿一件最简单的物品

在回收泊位房间内寻找 **A 工具箱（2kg／2分）**。靠近并把屏幕中央准星对准它，出现“拿起 A 工具箱”提示时按 **E**。

成功后，物品会出现在手中，右下角显示它的信息。一次只能拿一件；需要换手时，面向空旷地面按 **G** 放下。物品越重，移动越慢。

## 3. 完成第一次交付

拿着工具箱回到蓝色地面回收区。看到交付提示后：

1. 按 **E**，弹出交付确认窗口。
2. 按 **Enter** 确认。
3. 检查左上角变为 **1／3件、2／12分**，手中变空。

只把物品放在地上不会计分。必须完成上述交付确认。

## 4. 让Echo帮你调查一次

从门洞进入“02 储藏区”，寻找 **B 备件盒（4kg／4分）**。先不要拿起它：

1. 靠近并把准星对准备件盒。
2. 按 **R**，点击“调查准星目标”。
3. 按 **Esc** 关面板，给Echo让出门口和目标旁的位置。
4. 等它到达并扫描，再按 **R** 查看消息与目标摘要。

出现扫描效果或标记后，调查步骤就完成了。接下来由你按 **E** 拿起备件盒，带回泊位，按 **E → Enter** 交付。

此时进度应为 **2／3件、6／12分**。扫描本身不会加分、开门或自动交付；也可以直接搬运未扫描的物品。

## 5. 去检修间完成最后一趟

穿过储藏区进入“03 检修间”，找到 **D 仪器（6kg／6分）**。你可以再次让Echo调查，也可以直接拿起。

带回泊位，按 **E → Enter** 交付，进度变为 **3／3件、12／12分**。

这条 A工具箱 → B备件盒 → D仪器 的路线只是第一局示范。以后可以自由选择其他物品，只要同时满足件数与分数要求。标为“超限设备”的12kg物品超过8kg搬运上限，无法拿起。

## 6. 主动结束本局

达到目标不会自动结束：

1. 按 **Tab** 打开任务板。
2. 按一次 **Enter** 申请结算。
3. 出现“确认结束本局？”后，再按一次 **Enter**。
4. 看到“本次回收已完成”和用时，本局结束。

## 第二局再尝试的功能

- **Echo建议：** 先扫描物品，再按R选择“偏好：就近／高分／轻量”，点击“请求回收建议”。想让它前往建议目标时，点击“确认前往该目标”。
- **跟随与待命：** R面板可让Echo跟随、原地待命或取消当前任务；新指令会覆盖旧任务。
- **电量：** 首次成功扫描新目标消耗8电；重复扫描已知目标不重复扣电。让Echo跟你回泊位可充电，左下角会显示充电状态。
- **保存／继续：** F5保存，F9读档。
- **重开：** Tab打开任务板，N申请重新开始，Enter确认；会重置本局进度。
- **画面设置：** F10打开设置，修改后在15秒内确认。
- **文字交流：** T为可选脚本命令入口，当前版本的Echo尚未启用LLM自由对话。

## 卡住时先看这里

| 现象 | 操作 |
| --- | --- |
| E按了没反应 | 关闭面板、空手靠近物品，准星对准它；以“拿起”提示为准。普通布景没有拾取功能。 |
| 已拿到物品但不加分 | 带回泊位，E打开交付窗口，再Enter确认。 |
| Echo扫描后不知道下一步 | 查看摘要，然后自己搬运并交付；标记不会触发机关。 |
| Echo报告不可达 | 让开门洞和目标周围，重新发出调查指令。 |
| 没有回收建议 | 先让Echo扫描一个仍在场景中、未交付的可搬运物品。 |
| 三件物品交完仍不能结算 | 同时检查总分是否达到12分。 |
| 目标已达成但游戏没结束 | Tab → Enter申请 → Enter确认。 |
