# 第一轮试玩反馈：亮度修正与资源调研

2026-10-30，用户要求提高亮度、寻找场景/UI/HUD素材及类似GitHub项目。本轮按原普通灯光/UI委托执行小范围可读性修正；资源与功能先给出可核验候选，不擅自新增玩法、换推理框架或启动模型实验。

F01-V01独立模块：共享探索Volume曝光由+0.25改+1.0 EV、对比度5改2，保留ACES、冷蓝灰色调、颗粒/色差及已烘焙光照。曝光输入增加0.75档，约1.68倍线性光量，不等于最终SDR每个像素都亮1.68倍。三画质共用同一Profile，不新增实时灯/后处理pass；原Profile字节与旧Windows包逐文件SHA归档后再更新。

测试：1）独立原生三区×三画质同机位A/B，关闭随机颗粒/色差/频闪等干扰后比较线性亮度、暗像素和白色截断比例；每组亮度应增加至少10%，截断比例增量不超过1个百分点，保留1080p图片人工检查。2）既有后处理/管线用例复测。3）新Windows实际启动与回收路线，检查D3D11/HDR/SDR/脚本模式及错误日志。4）恢复原场景/全局绑定/播放选项并核验旧文件保护。测试计划不等于通过。

F01-R01调研：优先官方CC0同风格场景模块/设备、可复用面板及按键图标；逐项记URL、页面许可、用途/局限。GitHub查功能/玩法与许可/依赖，不批量导入代码。建议下一轮按“三区视觉识别→HUD信息层级→一次外部试玩”推进；具体新玩法和大范围美术替换另行确认。
