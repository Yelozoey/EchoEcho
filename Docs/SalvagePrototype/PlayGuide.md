# 回收原型操作说明

2026-10-29。R2已正式交付，最新玩法与程序入口请看[R2操作说明](R2_PlayGuide.md)。以下保留R1历史操作说明；R1结果见R1-V01_Final_TestReport.md。

Unity场景：Assets/EchoStation/Salvage/Scenes/ES_Salvage_Demo.unity。Windows目标入口：Builds/Salvage/EchoStationSalvage.exe。启动后点击游戏画面捕获鼠标；Esc释放鼠标，再点击继续。

| 操作 | 按键 |
| --- | --- |
| 移动、视角、跳跃 | WASD、鼠标、Space |
| 手电 | F |
| 对准近处物品拿起 | E；一次只能拿一件，单件上限8kg |
| 放下 | G；前方需要空闲有效地面，失败时物品保持在手 |
| 泊位交付 | 拿着物品走到蓝色泊位，E申请，Enter确认或Esc取消 |
| 查看任务/主动结束 | Tab；至少交付3件且总分≥12，Enter申请结束，再Enter确认；可取消后继续回收 |
| 重新开始 | 任务板N申请，Enter确认，Esc取消 |
| 独立手动存档 | F5保存，F9读档；确认中的操作先完成或取消再保存 |

三区依次为回收泊位、储藏区、检修间；储藏区有返回短路。任务板列出六种物品的重量/分数。可选A工具箱(2分)、B备件盒(4分)、D仪器(6分)，或C样本盒(3分)、F记录盒(5分)、B备件盒(4分)；都需亲自拿回泊位逐件确认交付。12kg设备不能搬，Echo不能代搬。

Echo在R1只跟随和返回充电：低于25提示，0时仍可低速跟随；在泊位附近自动充电，玩家与手电不扣电。R2扫描、警告、R面板和T文字将按已确认范围逐模块加入，当前不能用旧解谜版的蓝色标记流程理解本原型。

存档独立位于Application.persistentDataPath/Salvage/slot1.json，不迁移旧五区存档。重开重置当前局，F9仍可显式加载先前手动保存的档。首次试玩时长、目标硬件60FPS与正式美术尚待对应阶段实测，当前不是最终求职演示交付。
