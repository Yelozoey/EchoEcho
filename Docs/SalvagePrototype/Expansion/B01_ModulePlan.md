- 6列×4行，矩形与少量L形，90°旋转。
- 工具、电池和任务物共用空间；不堆叠；整理时暂停。
- 首个新版切片为环境危险＋工具操作，无战斗。

## B01工程约定（普通实现细节）

- 新自有目录SalvageExpansion，独立Domain程序集，noEngineReferences=true；不修改或引用已有场景与AI程序集。
- InventoryCell使用整数格坐标，X向右、Y向下。
- InventoryFootprint复制输入，拒绝空/重复/负格，归一到紧致包围框左上原点；形状不可变，允许未占用的凹角。
- 旋转次数按4取模，不镜像；每次转90°，坐标为(height-1-y,x)。四次旋转后形状还原。
- InventoryBoard为6×4不可变占用快照；复制输入、拒绝重复/越界占用。24位uint只作内部表示，不存角色/物品归属。
- 放置查询按实际占用格判断重叠，凹角允许嵌入其他物品；返回Valid/OutOfBounds/Overlap，拒绝整数溢出产生的假合法坐标。查询不提交摆放。
- 无新资源、包、管线资产或模型；测试临时绑定既有项目专用ForwardHDR后必须恢复原native/disk/dirty及场景布局。

## 独立用例

| 范围 | 期望 |
| --- | --- |
| 形状输入 | 空/重复/负坐标拒绝；外部数组变化不影响已构造形状；只读集合不能被改写 |
| 非对称L形 | 各旋转的格坐标/宽高正确；四次/负方向旋转一致；面积保持 |
| 边界 | 满6×4合法；贴右下边合法；负锚点/超过边界/int极值拒绝；1×6可旋转后放入 |
| 重叠 | 实占格碰撞拒绝；L形凹角里已有物品仍可嵌入；部分空间不能把包围盒当全占用 |
| 快照 | 外部占用列表变化不影响快照；非法占用拒绝；连续成功/失败查询不改变已占用格 |
| 组合检查 | 多组占用、四种方向、边界内外锚点与独立逐格参考判定一致 |
