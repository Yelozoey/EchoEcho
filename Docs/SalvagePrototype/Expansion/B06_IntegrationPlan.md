# B06 实施约定

按已批准切片集成，不更改七种物品、容量、目标或失败规则。复制已验收ArtV2流送主场景到独立Expansion目录，复用只读三区Addressables美术、4.5/4.5/5m净高、地面/墙碰撞、烘焙与探针；移除副本内旧游戏服务，创建新玩家与设备。旧场景/资源/构建不改。新增独立NavMesh，不覆盖旧数据。

泊位(5,0,12)，上/下通路(x12,z18/6)仍连通。上路蒸汽可在安全窗穿过或电池供风，下路扳手阀门可永久抑制；主电隔离器在核心漏电区域外，绝缘工具后逐个解除三夹具。数据口靠近隔离器，8秒校验可选；记录匣/仪器/样本争夺余格。至少测试“供风/上路”与“关阀/下路”两个主目标流程。

任务板Tab预览进度、教程和评价，核心已交付且在泊位时二次确认结束；N二次确认重开，F9恢复手动存档。教程可跳过/回看，按首次背包、扫描、供电/阀门、隔离、夹具、核心、交付分步提示。统计有效任务时间、额外价值、数据归档与危险次数，不把自动路线用时写成首次真人5–8分钟。

复用底层RoomSceneOwner/RoomDemandPlanner/RoomPresenter实现距离异步流送，任务目标租约及存档Epoch防旧任务提交；暂停租约覆盖玩家与Echo导航。新设备少量动态Renderer，沿用SRP Batcher。专用管线由现有Next三画质复制，替换仅新Renderer中的局部雾适配器；蒸汽区域雾密度随危险状态/通风改变，低档关闭，半分辨率16步。显示设置复用纯C#DisplayTransaction与独立Expansion settings目录，确认超时/失焦回退。普通画质/布局细节由本轮授权委托。

独立测试必须包含场景身份/独立Nav、两条完整路线、满包取舍、失败/读档/重开、教程跳过回看、任务暂停、流送真实句柄与卸载、UI互斥、三画质及渲染图；Windows跨进程与帧采样留V01。只在G04实际通过归档后实现。
