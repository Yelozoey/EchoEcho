# 环境回收灰盒试玩说明

独立Windows入口：`Builds/SalvageExpansion/EchoStationSalvageExpansion.exe`。Unity场景：`Assets/EchoStation/SalvageExpansion/Scenes/ES_EnvironmentalSalvage.unity`。旧回收版保留在SalvageNext目录，别启动错版本。实际交付验证以V01报告为准。

目标：亲手隔离故障设备，解除三个夹具，把数据核心装进有限背包带回泊位，确认交付后主动结算。其余三件物资和数据校验是可选成果。

WASD移动，鼠标观察，空格跳跃，F手电；E交互；I背包；背包内拖拽、R旋转、选择物品后装备/卸下/放下；探索时G放下手持物，R打开Echo；Tab任务和教程；F5保存，F9读档；F10显示设置。Esc关闭面板或释放鼠标，探索时左键重新捕获视角。

1. 在泊位按I，看看工具、电池占用的8格。装备电池或扳手，关闭背包。
2. 走向作业厅，观察蒸汽的黄灯预警、红灯喷发和安全窗口；可以绕另一条路线，或把电池插入通风口，或用扳手转动阀门。阀门操作期间危险仍运行。
3. 靠近并看向设备后按R，让Echo调查已发现目标。它只扫描、标记和报告；设备状态变化后旧报告会标过时。Echo电量和便携电池电量独立。
4. 装备绝缘工具，在危险区外对准主电隔离器按E；漏电停下后装备扳手，逐个瞄准三个夹具并按E。
5. 若想完整归档，先把便携电池插到数据口完成校验，再取核心。核心需要2×3格；整理、旋转、放下其他物品都由自己决定。额外仪器、记录匣、样本可选。
6. 回泊位按E，预览要交付的物资，Enter确认；工具和电池保留。按Tab主动申请结束，再确认。

背包整理、Echo面板和任务板暂停任务/危险/导航；操作阀门只阻断移动和视角。防护压力在红色危险区增加，离开后逐渐恢复，达到100本局失败。失败时F9恢复最后手动存档，或N/Enter确认重开；失败不自动传送、不自动交付，也不覆盖有效存档。

当前AI仍为脚本协作，UseLLM关闭；本轮没有训练或模型实验。预期首次流程5–8分钟，实际时长需玩家试玩记录。
