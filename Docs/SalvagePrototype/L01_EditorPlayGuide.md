# L01 编辑器试玩

本项只交付Unity编辑器入口，不新增Windows包。场景：Assets/EchoStation/SalvageExpansion/Scenes/ES_EnvironmentalSalvage.unity。

编辑器IME修复候选：补齐之前仅Windows独立程序启用的路径。首轮本人反馈仍只能输入英文已记录；请在本次代码刷新后重新Play复测，不能沿用旧Play会话判断。

1. 在Unity按Play，再点一下Game视图捕获游戏输入；按T打开“Echo通信”。标题应明确显示“脚本模式 · LLM未接入”。
2. 用微软拼音输入“电量”，选字后Enter发送：显示Echo电量，面板保持打开，游戏暂停。确认候选字的Enter不应误发送。
3. 输入“原地待命”：面板关闭，Echo待命，探索输入恢复；重新按T输入“跟随我”可恢复跟随。
4. 靠近并看向设备，输入“调查这个”：返回探索，等待Echo前往扫描。然后T输入“报告”，从左侧明确选择刚才设备查看已有扫描结果。未扫描目标应提示先调查。
5. 输入“调查未知对象”：应要求选择已发现目标，不自动选第一项。输入“替我开门”：应拒绝，不改变设备。
6. T面板打开时试I/R/Tab：背包、R菜单、任务板不应叠开；Esc返回后应恢复操作。正在操作阀门或其他面板时，T不应插入。

也可从R面板点击“文字通信 [T]”。需要点击“选择”时仅延续当前一条请求；关闭、成功读档或输入新指令会取消待选择请求。

本局显示最近100条消息，输入最多200字符、回复最多280字符；通信记录不写入存档，不被当作已知事实。成功读档会关闭面板、清空草稿及待选择状态，已有本局显示记录保留。设备/物品由玩家操作，Echo只扫描和提供信息。

当前仍为脚本。真实LLM现场问答是下一短任务，本项尚未执行；其他模型/训练/飞行也未启动。
