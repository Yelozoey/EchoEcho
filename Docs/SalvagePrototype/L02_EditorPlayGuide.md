# L02 本地AI现场问答：编辑器试玩

本项是只读实验入口。Qwen3-0.6B本轮真实诊断JSON20/20、内容8/20，未达到质量门槛。会出现漏信息、串目标与虚构内容；界面明确标注，旁边保留扫描报告供对照。默认仍为完整脚本流程，无需下载或打包。

场景：Assets/EchoStation/SalvageExpansion/Scenes/ES_EnvironmentalSalvage.unity。

1. Play后点击Game视图，完成或跳过原有引导，找到可调查设备，例如蒸汽阀门。对准它，T输入“调查这个”，返回探索等待Echo实际到达并扫描。
2. 再按T，点击右上“启用本地AI问答（实验）”。首次需要加载本地权重，等待“本地AI已就绪”；可取消加载回脚本。
3. 点击左侧“问答＋设备名”选定对象，再输入“这个应该如何处理？”“操作它需要注意什么？”。问题进入真实本地模型，回复标“本地AI实验”，下方同时显示此次有效扫描摘要。通常需数秒。
4. 试“这个设备多少伏？”或“门后密码是什么？”。报告并未提供这些事实；如果AI编造数字，即为失败样例，不能当线索或密码使用。通过对照来源体验模型局限，不把台词当作已核验事实。
5. 推理时可点“取消AI请求”，也可Esc返回探索。旧请求不得在重开面板后突然显示。跟随、待命、取消和调查仍走脚本，照常关闭面板执行；它们的回执不算模型输出。
6. 状态变化后再问旧报告，应要求重新扫描；未扫描目标应阻止进入模型。AI不会帮你关闭阀门、接电、解夹具或拿物品。
7. 点击“关闭AI · 返回脚本”即可恢复L01；“电量”“报告＋目标名”始终是标注清楚的脚本查询。AI开关与对话仅本局保留，不新增存档字段。

本轮自动模型实验已结束，不再追加候选或独立集。本人主动试玩与自动质量实验分开记录。测试后反馈：选中哪个设备、问了什么、回复是否符合来源，以及取消/切回脚本是否正常。本项亲测后再决定下一短任务；没有训练、飞行改造、其他模型或云服务。
