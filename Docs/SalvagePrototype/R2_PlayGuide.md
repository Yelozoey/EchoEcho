# R2 回收与Echo协作试玩说明

2026-10-29。R2已交付：Editor123项回归、Windows五进程实际通过。结果见../Tests/SalvagePrototype/Reports/R2-V01_Final_TestReport.md。

Windows入口：`Builds/Salvage/R2/EchoStationSalvage.exe`。Unity入口：`Assets/EchoStation/Salvage/Scenes/ES_Salvage_Demo.unity`。原R1构建仍保留在上一级。本版使用脚本Echo，LLM与训练均未启动；当前是三区灰盒，正式美术/流送/性能打磨在R4。

先点击游戏画面捕获鼠标。WASD移动、鼠标观察、Space跳跃、F手电。E拿起准星对准的近处物品，一次一件、上限8kg；G放在前方空闲地面。拿着物品回蓝色泊位，E申请交付、Enter确认或Esc取消。至少交付3件且合计12分后，Tab打开任务板，Enter申请结束，再Enter确认。可以取消结束继续探索；任务板N申请新局，Enter确认。

推荐首条路线：泊位附近工具箱A（2分）→储藏区备件盒B（4分）→检修间仪器D（6分），每件都亲自搬回泊位确认。另一条合法路线为样本盒C（3分）→记录盒F（5分）→备件盒B（4分），可走储藏区返回短路。12kg设备不可搬。

Echo操作不需要打字：先用准星对准物资，R打开面板，点“调查准星目标”，Esc回探索；Echo走到附近再扫描，成功后显示短报告和已扫描标记。R还可跟随、待命或取消当前任务；已发现目标可从面板或任务板入口选择。待命后的调查结束仍回待命，需要跟随时再明确点“跟随”。手持/已交付的已知记录仍可查看，不能再让Echo调查。

T为可选文字通信，Enter发送、Esc关闭。可试“跟随我”“原地待命”“调查这个”“电量”“已知信息”“任务建议”；目标含糊时明确选择。它使用预设脚本指令，并非自由语言模型。Echo不能搬运、交付、开门、接线或修设备。

蓝灯平静、黄灯调查/扫描、红灯危险或低电。扫描第一次成功扣8电；取消、失败、已知重复不重复收费。电量低于25提示，耗尽仍可低速跟随，在泊位附近自动充电。配电箱与泄漏管段仅提供只读警告，没有伤害、封路或额外解谜；扫描也不加分、不解锁通路。玩家可不扫描而完成回收。

若扫描受阻，关闭面板、让开机器人与目标之间的视线，再调查。若目标不可达，取消后选择其他有效目标；Echo不会瞬移。Esc关闭Echo面板后恢复操作，普通探索中Esc释放鼠标，再点击画面继续。

F5手动保存，F9读档。只使用`Application.persistentDataPath/Salvage/slot1.json`，不读取旧五区槽。v2保留发现、基础模式和最近50条对话；不续跑进行中的任务或未发送文字。有效R1档会保留原始备份`slot1.json.r1-v1.json`再升级；旧R1程序不支持读取v2。新局重置当前局，原手动档仍可显式F9读取。关闭窗口或Alt+F4退出。

首次外部试玩时间、目标硬件60FPS与Windows人工输入法兼容性仍须对应实测；自动路线不代表首次5分钟体验已验收。
