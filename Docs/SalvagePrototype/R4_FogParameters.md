# R01c-3 局部体积雾与实时灯散射

2026-10-30，N08常规实现；c-2门禁2/2已过。旧S2雾坐标与恢复逻辑固定于原实验室／通道，保留其源码／资产；只替换新版专用Renderer内旧雾Feature，新增NextFogField／View／Feature／Shader。

三个短连接AABB：中心(12,1.3,6)、(12,1.3,18)、(24,1.3,12)，尺寸3×2.6×3，密度0.06／0.08／0.06。半分辨率R16G16B16A16、16步积分、深度止步、边缘双边复合。8m内且视锥涉及Fog Box才提交；房间主体不填雾，Low关闭。只在Game／Base相机运行；不加粒子。

四个实际Realtime局部灯（手电、扫描、两故障灯）的实时启用、世界位置、方向、range、spotAngle与color/intensity进入Shader距离／锥角散射；环境底色(0.035,0.055,0.075)，LightStrength默认1、允许0–4用于选项／对照。不访问未知线索或改变通路。主循环无CPU风动画，纹理／参数缓冲复用。

F244实读原副本有6盏局部灯，包含R2遗留两盏与新版故障灯重复；仅新版移除旧两个Light组件（非危险目标对象），保留故障灯，修正为实际预算4并重绑ShadowBudget。旧R2及逻辑权限不改；首次配置未保存／未启动测试。
