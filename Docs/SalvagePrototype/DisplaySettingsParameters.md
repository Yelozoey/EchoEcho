# P01a-3 画质与显示设置实施参数

2026-10-30，a-1/a-2全部独立测试通过后执行，依据N08普通UI/参数委托；不是已验收结果。

入口F10和HUD设置按钮；高中低复用现有三套专用管线。显示提供1280×720、1600×900、1920×1080，窗口/无边框全屏/独占全屏；Windows实际窗口允许调整大小。性能基准仍1080p，开发机不能证明最低硬件60FPS。内部HDR/SDR与D3D11固定。

应用使用事务：先记下当前实际显示与画质，请求后最多3秒等待原生状态匹配，匹配后15秒保留/还原确认；超时、取消、失焦/外部改动或写入失败还原之前配置，异步还原最多3秒，失败保留明确错误状态。显示配置只在成功确认后写盘，不能点击即覆盖之前有效值。退出/禁用时取消未提交事务，实际Windows复测所有分支，不以Editor假显示后端代替。

新配置独立persistentDataPath/SalvageNext/settings.json，版本1/UTF-8/严格字段和类型/SHA256/上限4096字节、原子临时/备份、坏档/未来版保留；不改已有slot1保存格式、不读写R2。支持捕获用户调整后的640–3840×480–2160窗口作还原值，菜单仅三种已列分辨率。无配置默认Medium/1080p窗口；读取不自动写盘。画质属于已存进度字段，F9可恢复该档画质，面板随Session变化刷新；显示偏好独立。

UseLLM保持false，界面明确本轮AI未通过门禁/脚本模式，禁用启用路径，不把开关变成绕过No-Go的入口。设置不改三个建议偏好或机器人权限。

模块顺序：a3-1配置格式/原子存储；a3-2纯事务/假后端独立测试（只能证明状态与恢复逻辑）；a3-3真实Unity后端/模态UI与会话整合；随后Windows真实分辨率/模式/回滚与性能。输入借用既有UI拥有权规则，进入前拒绝与交付/结算/其他面板冲突，关闭不解除别人的UiBlocked；加载仍由StreamInputLease控制，不清它的状态。

设置面板打开时忽略F5/F9，防止待确认的临时画质写入进度槽或读档与回滚竞争；关闭后原存读档热键恢复。

Windows首轮发现Screen模式可能先反映请求值、随后DXGI回退。应用阶段须连续1秒观察匹配才允许确认，仍在3秒总预算内；不接受的独占模式应还原，不记独占成功。验证需区别系统真正接受与拒绝后安全还原。
