# S3-C01 摘要快照、目标范围与真实Token预算

2026-10-26，I04归档后开始。先a数据/目标范围及测试归档，再b检索脱敏/真实token预算。这里不接执行权限、GameObject或Prompt正文；后续C02/E01分别接线。

a：复制不可变MemorySnapshot（其类型没有原文），复制目标纯值候选（ID、名称、区域、可用、调查/危险许可、当前可见、距离）。最多128候选，重复ID/坏字段拒绝。只选当前区域可见且允许调查或警告的可用目标，或已发现线索KeyMarker/已知危险状态明确指向的可用目标；至多8个，优先问题明确提及、再当前可见/距离/ID稳定排序。不把全场目录作为允许列表。实际可见性由后续主线程适配器采样并重验。

b：复用S2相关摘要检索与优先级/衰减，截取完整条目，最多8条/1200UTF8字节/512真实tokens；只从末尾删除低优先级完整条目，不截断摘要。上下文不发送Password字段值，已知密码在摘要/标题/状态内出现也替为“[密码已归档]”；明确询问的最终密码由已确认S2可信知识规则复述，模型无需持有数字。原存储不删改，未知条目不能从全局故事目录加入。

目标目录只渲染ID/名称和允许行为，JSON字符串转义；名称不夹带原文、密码或隐藏字段。其token计入C02完整1536输入预算，记忆512预算单独核算。玩家输入最多200个C#字符且UTF16有效；role字符串按普通文本编码，不自动形成模型特殊token。

独立测试包含快照源变更后稳定、候选拷贝/容量/重复、各区域/可见/许可/已知引用边界、8项排序、无FullText入口；b与真实上游tokenizer验算字节和token、数字/Unicode边界、完整条目裁剪、脱敏、衰减和新请求新快照。
