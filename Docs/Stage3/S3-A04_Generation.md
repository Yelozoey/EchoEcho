# S3-A04 完整自回归生成合同

2026-10-26，前置A03已10/10归档。按两个叶模块推进：a用确定性后端验证停止/预算/取消/UTF8/greedy协议，独立通过后b跑真实模型完整生成。测试替身不计为真实LLM成功。

- ITokenModel只暴露纯ID输入、Owner只读logits、Step与Reset；正式QwenOnnxBackend继续真实后台Owner约束。生成器无Unity对象。
- greedy/温度0，平分取最小ID；只考虑真实tokenizer定义的ID。EOS为151643/151645；其他特殊角色标记不作为普通输出选择。8个普通added tokens保持模型词表语义，不获得工具权限。
- 输入最多1536、生成最多256（包括选中的EOS）；raw UTF8最多4096字节；20秒单调时钟逻辑超时。冷加载30秒由I01单独封装。每次请求新prefill，所有出口finally清KV，禁止跨请求续旧历史。
- 生成过程中每次原生调用前后检查取消/超时，不主线程等待、不中止线程。超时或取消没有可执行结果。达到token上限标记未完成；EOS成功必须严格UTF8完整，不把截断字节替换后当成功。
- 仅插入可选token约束接口：约束实际logits采样，不能修补坏字符串。完整意图JSON grammar在J01 schema/解析模块独立实现和测试，当前raw模式不承诺合法JSON；G01已知Markdown倾向保留为未决质量问题。
- 最终结果包含原始文本、实际生成IDs、停止原因、耗时和解码模式；不直接写记忆/游戏。J01/J02及E模块后续决定是否可以执行。

独立用例：固定/平分greedy、EOS/上限、4KiB、取消与20s边界、UTF8不完整、未知token、reset生命周期、约束接口、真实完整模型输出/冷暖时延/原始IDs；Unicode/model精确参考沿用A02/A03。
