# T01 结构约束影响定位

v6/v7/v8/v9的Prompt改版收益不稳定，新D独立84/100失败。先定位，不继续无依据堆例子。

固定六个已见例，覆盖六种意图：C001、C018、C048、C057、C061、D098。相同v9正式Preparation/inputIDs、固定Q3包、CPU4/greedy/非思考/20秒/256tokens，逐条各做紧凑JSON约束与无约束各一次。每次独立KV并实际完成后等300ms；输出原样保留，不剥Markdown、补JSON或按自然语言重写标签。

独立测试只要求12次真实调用和Owner清理/输入一致性，语义各自统计，不能将定位测试通过视为质量通过。无约束从不接游戏，只为判断紧凑空白/固定键序是否影响原始意图。若约束明显改变语义，再考虑保持六Schema的纯结构语法改进并独立测试；否则不擅自放宽生成约束。
