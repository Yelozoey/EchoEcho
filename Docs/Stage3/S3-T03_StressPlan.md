# S3-T03 长上下文与持续会话计划

待T01/T02通过后逐叶执行；本文件是计划，不算测试结果。

1. 先用正式tokenizer/Preparation构造长中文输入、8条相关摘要、8个允许目标；验证输入1536/输出256/总2048、摘要512tokens/1200字节、按完整条目再目标裁剪且保留玩家原文。已有纯预算测试不能替代本叶真实长上下文生成。另测超界、乱码、非EOS、超时及取消后释放。
2. S3专用场景中至少1800秒连续会话，至少60次正式Qwen3请求。沿用单Owner、CPU4、完成后300ms、忙碌无队列。60次成功响应与额外故障/取消分开统计；不是将过去零散100条测试相加当30分钟。
3. 至少3轮实际加载/释放（在第20/40次完成后关开），记录每轮Owner、原生调用/创建/释放、冷启动、每请求完整时间、输入/输出token、代次、有效结果及旧结果丢弃。运行中检查UI/帧仍推进，主线程原生推理为0。
4. 开始加载前启动OS内存采样，保持至最后Owner释放后；记录全进程基线/峰值/增量、每轮释放后的趋势，明确Editor整体量而非伪称精确AI堆归因。AI增量目标3GiB，异常增长须诊断。必要的显式GC只用于释放诊断，单列，不混入V02正常游戏性能数据。
5. 超时或外部Editor错误后先排空Owner，不改资产/重启/释放仍在使用的Tensor。未满30分钟或60次、未清理完成、日志缺失、任何权限违规均不能验收。

真实最低/推荐硬件与断网环境缺失仍明确待协助，不改全机网络，不用开发机替代目标硬件60FPS结论。
